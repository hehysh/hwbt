首个可试用版本。在 Windows 上通过蓝牙给华为 GT 系列手表上传音乐，不需要华为运动健康、不需要 root，也不需要 Android 手机。

## 下载

`HuaweiMusic.exe` —— 单文件、免安装，Windows 10/11 64 位，双击即用。

SHA-256：`d725350939cd0e8102eea67c5cb65073c9048810b516d1652e2f71f803147750`

## 功能

- 扫描并连接附近手表；首次配对后在本机记住密钥，下次一键连接
- 拖拽或选择多个音频文件，逐个上传并显示实时进度
- 显示型号、固件、电量、剩余空间、已存歌曲数
- 查看手表上已有的歌曲列表（标题 / 歌手 / 文件名）
- 中文界面，内置诊断日志，可一键导出

## 使用前提

1. 手表需先在华为运动健康里完成初始化和配对。
2. 连接电脑前，**先在手机上断开花为运动健康**，否则电脑连不上。
3. 首次配对时手表可能弹确认框，请在 45 秒内点确认。

## 支持格式

mp3 / m4a / aac / flac / wav / opus。

## 已知限制

- 只实现 HiChain 配对；更老的 PIN 配对设备会提示不支持。
- 暂不支持删除手表上的单曲（参考实现只有歌单操作）。
- 未在真机验证过所有型号；遇到问题请勾选「调试日志」后导出反馈。
