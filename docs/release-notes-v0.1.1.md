修复真机上最常见的连接失败。

## 这一版改了什么

**1. 自动请求 Windows 配对**

手表对加密特征要求“系统级配对”。之前的版本直接写数据，Windows 会回
`GATT Protocol Error: Write Not Permitted`。现在检测到这类错误时，程序会自己调用
Windows 的配对接口，成功后重试一次，日志里能看到「正在请求 Windows 配对…」。

**2. 报错不再是天书**

`Write Not Permitted` / `Insufficient authentication` 现在会附带三步排查提示
（手机断开/解除配对 → Windows 蓝牙设置里配对 → 再连接）。

**3. 文档**

README 的使用方法新增「在 Windows 里先配对一次」这一步，FAQ 新增
「手表上出现二维码 / 连接新手机」——那是华为运动健康专用流程，电脑不需要扫码。

## 使用顺序

1. 手表退出「连接新手机」二维码界面，回到表盘。
2. 手机：华为运动健康 → 设备 → 断开连接；仍不行就「解除配对」。
3. 电脑：设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙 → 选中手表配对。
4. 打开本程序 → 扫描 → 连接。
