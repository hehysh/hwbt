修掉真机上最常见的 `Write Not Permitted` 失败。

## 根因

`GATT Protocol Error: Write Not Permitted` 是 ATT 错误 **0x03**，含义是“这个特征不接受你用的写入方式”，
**不是**缺配对（缺加密会是 0x05 `Insufficient Authentication` / 0x0F `Insufficient Encryption`）。

华为 FE01 特征在部分机型（如 GT 2e）上只支持 **Write Without Response**。之前的版本一律用
“带响应写入”，手表就直接回 0x03；上一版又把它误判成“需要系统配对”，于是去调 Windows 配对，
结果 GT 2e 进入“连接新手机”二维码界面并停止广播，越修越连不上。

## 这一版改了什么

**1. 按特征属性选择写入方式**

连接后读取 FE01 的 `properties`，写进日志：

```
FE01 特征属性：write-without-response, notify
```

只支持无响应写入时自动切换；两种都支持时保留用户设置（「快速模式」）。

**2. 0x03 时自动换一种写法重试**

万一属性判断不准，第一次写入被拒后会立刻换成另一种写入方式重试一次，并记住结果。

**3. 不再把 0x03 当成配对问题**

0x03 不再触发 Windows 系统配对（那会让手表进二维码）。只有真正的加密错误才会请求配对。

**4. 报错说明重写**

现在明确告诉你：不要在 Windows 蓝牙设置里配对手表、手表别停在二维码界面、手机先断开；
并提示导出日志（里面有 FE01 属性行）。

**5. 扫描为空时保留「上次的设备」**

手表被 Windows 连上后可能不再广播，此时下拉框仍保留上次的地址，可以直接点「连接」。

**6. README 纠正**

删掉上一版建议的“先在 Windows 里配对一次”，改为明确警告；FAQ 增加 `Write Not Permitted` 条目。

## 使用顺序

1. 手表退出「连接新手机」二维码界面，回到表盘。
2. 手机：华为运动健康 → 设备 → 断开连接；仍不行就「解除配对」。
3. **如果之前在 Windows 里配过对**：设置 → 蓝牙和其他设备 → 删除该手表。
4. 打开本程序 → 扫描 → 连接（**不要**在 Windows 里配对手表）。
