这一版只加一件事：**把手表里的歌单导出成 TXT。**

## 怎么用

连接手表 → 点「手表歌曲」→ 列表窗口右下角新增「导出 TXT」→ 选保存位置即可。

导出的文件长这样：

```
华为手表歌曲列表
导出时间：2026-10-31 12:35
设备：HUAWEI WATCH GT 2e
共 12 首

01. 夜曲 - 周杰伦
02. 晴天 - 周杰伦
03. Intro
```

- 每行一首，格式是 `序号. 标题 - 歌手`；没有歌手时只写标题，标题为空时退回文件名。
- 编码为 **UTF-8 带 BOM + CRLF 换行**，Windows 记事本直接打开不会乱码，也不会挤成一行。
- 默认文件名是 `手表歌曲-20261031-1235.txt`，带时间戳，多次导出不会互相覆盖。
- 手表上没歌（或该型号不返回列表）时，「导出 TXT」是灰的。

命令行同样可用：

```bash
hwmusic songs                # 只打印
hwmusic songs -o songs.txt   # 顺便导出
```

## 实现说明

- 新增 `src/hwmusic/songlist.py`，把「列表 → 纯文本」的渲染独立出来，GUI 和 CLI 共用同一份实现，测试也能直接覆盖。
- `WatchSongsDialog` 增加「导出 TXT」按钮，导出失败会弹窗提示具体原因（例如目录没有写权限），不会静默失败。
- 导出时会带上手表型号，方便日后对照是哪块表。

## 测试

- 新增 7 项测试：标题/歌手拼接、缺标题时退回文件名、无歌手时只写标题、
  表头与编号格式、空列表、未知设备时不写「设备：」、两位数序号对齐（共 109 项）。
- 另外用离屏 Qt 实测了一次真实导出：BOM 正确、换行全是 CRLF、中文正常、空列表时按钮置灰。
